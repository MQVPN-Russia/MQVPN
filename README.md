# MQVPN — официальный VPN-сервис

**MQVPN** — VPN-сервис для России. Подключение доступно на iPhone и iPad, Android, Windows и Android TV.

- Официальный сайт: [mqvpn.lol](https://mqvpn.lol/)
- Личный кабинет: [mqvpn.lol/lk](https://mqvpn.lol/lk)
- Инструкции: [mqvpn.lol/instructions](https://mqvpn.lol/instructions)
- Telegram-канал: [@MQVPN](https://t.me/MQVPN)
- Telegram-бот: [@MQVPN_Robot](https://t.me/MQVPN_Robot)
- Поддержка: [@MQVPN_Support](https://t.me/MQVPN_Support)

Этот репозиторий принадлежит сервису MQVPN и служит его официальной публичной страницей на GitHub. Здесь нет исходного кода приложения, серверной инфраструктуры, ключей подключения или пользовательских данных.

## Как отличить официальный MQVPN

Официальный сервис использует домен **mqvpn.lol**, Telegram-канал **@MQVPN**, бот **@MQVPN_Robot** и этот репозиторий **github.com/MQVPN-Russia/MQVPN**.

MQVPN не связан с другими GitHub-проектами, пакетами или репозиториями с похожим названием, если ссылка на них не опубликована на [официальном сайте](https://mqvpn.lol/o-mqvpn).

## Коротко о подключении

1. Войдите в личный кабинет MQVPN.
2. Выберите своё устройство.
3. Установите рекомендованное приложение.
4. Добавьте ключ по инструкции и включите VPN.

Актуальные шаги и ссылки на приложения всегда опубликованы на сайте. Не используйте случайные установочные файлы и не передавайте ключ подключения другим людям.
